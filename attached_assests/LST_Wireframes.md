## Design Principles

### Core Philosophy
The Let's Talk (LST) app follows a **dark-mode-first** design approach, prioritizing visual comfort, reduced eye strain, and modern aesthetics. The design emphasizes ephemeral content, real-time engagement, and intuitive navigation.

### Key Design Principles
- **Dark-First:** Default to dark backgrounds with accent colors for key actions
- **Mobile-First:** Design for mobile screens first, then scale up for desktop
- **Ephemeral Awareness:** Time-bound elements are prominently displayed
- **Threaded Discussions:** Visual branching to represent conversation depth
- **Minimal Cognitive Load:** Clean layouts with clear visual hierarchy
